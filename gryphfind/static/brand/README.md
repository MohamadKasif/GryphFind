# Official artwork (optional)

Drop official image files here to replace the built-in gryphon drawing:

- `logo.png` (or .svg/.webp/.jpg) — shown in the header. A square image works best.
- `mascot.png` (or .svg/.webp/.jpg) — shown large on the home page. A transparent PNG looks best.

Restart isn't needed; refresh the page. Only add artwork you have permission to use.
